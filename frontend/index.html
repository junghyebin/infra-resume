소개

WMS(창고관리시스템)와 MES(제조실행시스템)를 3년 10개월간 개발·운영하며, 장애가 생기면 추측보다 로그와 데이터로 원인을 좁혀가는 방식을 익혔습니다.

고객사의 랜섬웨어 사고를 겪으며 보안 사고가 업무 연속성에 주는 영향을 체감했고, IT 환경을 안전하게 지키고 운영하는 일로 전문성을 넓히고 있습니다.

기술

인프라·클라우드

  • Linux, 서버·네트워크 기초
  • AWS (IAM, S3, RDS 등)
  • VMware 가상머신 구성

개발·운영

  • C#, React, DevExtreme, Kotlin(Android), MSSQL
  • GitLab, Jenkins, GitHub

경력

포메이션랩스(주) R&D팀

2022.04 – 2026.01 (3년 10개월)

창고 관리 시스템(WMS) 운영·유지보수

  • 현장 작업자용 PDA(Android) 및 Web 화면 개발·유지보수
  • 현장 단말기 적용을 위한 Android APK 빌드 및 배포
  • DB History 테이블 역추적으로 재고 불일치 원인 규명

제조 운영 시스템(MES) 운영·유지보수

  • 공구·설비·생산 관리 시스템 DB 초기 세팅 및 Web 화면 개발
  • GitLab 소스 관리, Jenkins 기반 운영 환경 배포
  • DB 메일 기능을 활용한 실시간 장애 알림 환경 구축

사내 운영 효율화

  • Obsidian 기반 팀 기술 블로그 구축 및 트러블슈팅 사례 문서화
  • 공통 UI 템플릿 표준화 참여

프로젝트

Cloud Resume Challenge

지금 보고 있는 이 이력서 사이트를 AWS 위에 직접 구축하는 프로젝트입니다. 정적 웹사이트 호스팅, HTTPS, 서버리스 방문자 카운터, IaC, CI/CD까지 단계별로 진행하고 있습니다.
